ПД-14 — расчёт без заданной окружной скорости

Если вы не знаете $U$, включите автоматический режим: программа возьмёт желаемую работу ступени, найдёт число ступеней и вычислит окружную скорость из целевой $\psi^*$ с учётом целевого КПД ступени. Дополнительно рассчитываются вентилятор по полному расходу через двигатель, треугольники скоростей с числом Де Халлера и $M_{w1}$ на периферии, а также кинематика по трём сечениям по закону закрутки $c_u r = \mathrm{const}$.

Исходные данные

Если включено, поля $U$ не используются: скорость считается по целевой работе ступени, целевому КПД и $\psi^*$.

Треугольники скоростей (среднемассовые параметры ступени)

Скорости даны по модулю. Для компрессора $c_{2u} = c_{1u} + \Delta c_u$, для турбины $c_{2u} = c_{1u} - \Delta c_u$. $\Delta c_u = \psi \cdot U$. Число Де Халлера $W_2/W_1$ нормируется не ниже ≈ 0,72; $M_{w1}$ на периферии желательно не выше ≈ 0,95.

Как работает автоматический режим

Вы задаёте желаемую работу одной ступени $\Delta h_{ст.зад}$ и целевой КПД ступени $\eta_{ст}$. Тогда число ступеней:

n = ceil( Δhиз / (Δhст.зад · ηст) ) — для компрессора
n = ceil( Δhиз · ηст / Δhст.зад ) — для турбины

После округления вверх окружная скорость находится из целевой нагрузки:

U = √( Δhиз / (ηст · n · ψ*) ) — компрессор
U = √( Δhиз · ηст / (n · ψ*) ) — турбина

Здесь $\Delta h_{из}$ — изоэнтропическая работа, $\eta_{ст}$ — целевой КПД ступени (учитывает, что реальная работа компрессора больше, а турбины меньше изоэнтропической).
